ERROS COMUNS E SOLUÇÕES:
-------------------------
Erro 401 Unauthorized:
  - Verifique se o Worker está atualizado
  - Verifique se o token está no localStorage
  - Verifique se o token está sendo enviado no Authorization header

Erro CORS:
  - Verifique se o Worker tem os headers CORS configurados
  - Verifique se a origem está configurada corretamente

Login funciona mas dados não carregam:
  - Verifique se o Worker foi atualizado no Cloudflare Dashboard
  - O código local está atualizado, mas o Worker pode estar com código antigo
