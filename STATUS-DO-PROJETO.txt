INFORMAÇÕES TÉCNICAS:
--------------------
- Worker URL: https://rainha-de-copas-admin.emanuelcamarg9.workers.dev
- API autenticada: /api/{tasks,schedule,team,lore,announcements,score,login,logout}
- API pública (sem login, só GET): /api/public/{tasks,schedule,team,lore,announcements,score}
- CORS Origin: https://manelcamarg.github.io
- Auth: header "Authorization: Bearer <session_id>" (token no localStorage
  como 'admin_token', sessão em 'admin_session', email em 'admin_email')
- Score: GET/PUT /api/score {calculated, bonus, total} - bonus fica na
  tabela settings (key='score_bonus')

ERROS COMUNS E SOLUÇÕES:
-------------------------
Erro 401 Unauthorized:
  - Sessão expirou (24h) → fazer login novamente no admin
  - Token ausente → verificar localStorage 'admin_token'

Erro CORS / "Failed to fetch" no admin:
  - Worker com código antigo → atualizar no dashboard
  - Se persistir, abrir F12 > Console e mandar o erro real

Toast "Erro 500" + "no such column":
  - Campo enviado que não existe na tabela → o Worker agora filtra
    colunas automaticamente (filterColumns), mas se acontecer, verificar
    se o frontend está mandando campo errado

Site mostra dados antigos:
  - Cache do navegador → Ctrl+Shift+R
  - Se o admin salvou mas site não mudou → verificar se Worker está
    atualizado e se a tabela settings existe (para /api/score)

D1 console "No SQL statements detected":
  - O texto não foi colado na caixa de query → clicar dentro da caixa
    antes de colar; rodar statements grandes em partes
