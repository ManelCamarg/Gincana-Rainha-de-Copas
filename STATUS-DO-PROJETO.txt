PROBLEMA ENCONTRADO EM 16/11/2026 (CORRIGIDO NO CÓDIGO):
------------------------------------------------------
Erro 500 (error code 1101) em TODAS as rotas autenticadas (/api/tasks,
/api/schedule, etc), mesmo com token válido.

CAUSA RAIZ:
- verifySession() fazia "SELECT user_id, email FROM sessions", mas a tabela
  sessions NÃO tem coluna "email" → D1 lançava exceção → erro 500.
- Bug secundário: expires_at era gravado em formato ISO ("2026-11-17T...Z")
  e comparado com datetime("now") ("2026-11-16 12:00:00") — comparação por
  string fazia sessões quase nunca expirarem.
- handleLogout() só apagava a sessão via cookie, não via token Bearer.

CORREÇÃO APLICADA (commit 30d7d55, já no GitHub):
- SELECT corrigido para "SELECT user_id FROM sessions ..."
- expires_at agora gravado como "YYYY-MM-DD HH:MM:SS" (formato compatível)
- Logout agora apaga a sessão também quando usa Bearer token

- Cloudflare Worker precisa ser atualizado manualmente no Dashboard


ERROS COMUNS E SOLUÇÕES:
-------------------------
Erro 401 Unauthorized:
  - Verifique se o Worker está atualizado
  - Verifique se o token está no localStorage
  - Verifique se o token está sendo enviado no Authorization header

Erro CORS:
  - Verifique se o Worker tem os headers CORS configurados
  - Verifique se a origem está configurada corretamente

Login funciona mas dados não carregam:
  - Verifique se o Worker foi atualizado no Cloudflare Dashboard
  - O código local está atualizado, mas o Worker pode estar com código antigo
